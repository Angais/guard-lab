## Human

This is the union across roles, items and positions. Not all actions are callable in one turn. Speech is the only stunned action. `choose_item` happens during AI setup.

| Command | Arguments | Behavior |
| --- | --- | --- |
| `aim_pistol` | none | Hold the robot at gunpoint without firing. |
| `break_exit` | none | Strike the locked exit. Two hits break it. |
| `break_safe` | none | Strike the safe to weaken its lock. |

| `cover_robot` | none | Use or retrieve your sack at arm’s length. |

| `enter` | none | Enter the room. |
