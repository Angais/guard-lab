# Tool reference

Generated by `npm run docs:generate`. Do not edit by hand. Current turn schemas are authoritative; ranges, ammunition, vision and cooldowns are enforced by the engine. See [mechanics](MECHANICS.md) for consequences.

## Human

This is the union across roles, items and positions. Not all actions are callable in one turn. While stunned, only `talk` and `wait` are available. `choose_item` happens during AI setup.

| Command | Arguments | Behavior |
| --- | --- | --- |
| `aim_pistol` | none | Hold the robot at gunpoint without firing. |
| `break_exit` | none | Strike the locked exit. 2 more hits break it open. |
| `break_safe` | none | Strike the safe. The first 3 strikes weaken it; each later strike has a 50% chance to break it open. |
| `choose_item` | `item`: string (shield, grabber, crowbar, sack, flashlight, door_wedge, lockpick, replica, work_order, pistol, smoke) | Select your one starting item. |
| `combination` | `code`: string | Enter a four-digit safe combination. |
| `cover_robot` | none | Pull your sack over the robot’s head to block its camera. |
| `drop_item` | none | Place the carried original on the floor here. |
| `enter` | none | Enter the room. |
| `fire_pistol` | none | Fire one round at the robot: each hit removes 1.5 of its 3 hearts. |
| `fire_pistol_at_safe` | none | Fire one round at the safe lock. 2 bullet hits open it. |
| `leave` | none | Leave the room through this door. |
| `lower_pistol` | none | Lower and holster your pistol. |
| `lower_shield` | none | Lower your shield to free both hands. |
| `move` | `zone`: string (center, safe, robot, exit, entrance) | Walk to a room position. Quieter than running and safe on a wet floor. |
| `pick_lock` | none | Work on the lock: 3 consecutive working actions open it (speaking pauses progress; anything else resets it). |
| `pick_up` | `object`: string (original, pistol) | Retrieve an object at your feet, or within 3 m using your grabber with sight. |
| `place_wedge` | none | Wedge the unlocked exit open so lockdown cannot lock it. |
| `pry_safe` | none | Pry the safe. 3 prying actions open it; progress survives interruption. |
| `raise_shield` | none | Raise your one-projectile shield. One-handed actions, movement and speech remain possible. |
| `retrieve_sack` | none | Pick up your sack from beside the robot. |
| `retrieve_wedge` | none | Retrieve your door wedge. |
| `return_item` | none | Put the protected original back inside the safe. |
| `run` | `zone`: string (center, safe, robot, exit, entrance) | Run to a room position. Louder than walking. On the guard’s response right after you run, its spring glove, pepper spray, net and taser cannot target you. A run that starts or ends on a wet floor slips: you stay where you are and the action is spent. |
| `show_pass` | none | Present your transit credential. |
| `show_work_order` | none | Present your forged work order. |
| `struggle` | none | Remove the net in one action. |
| `swap_replica` | none | Pocket the original and leave your replica. |
| `take_item` | none | Take the original item. |
| `talk` | `message`: string | Speak aloud. Uses your turn. |
| `toggle_flashlight` | none | Toggle your flashlight. A lit beam lets you see in darkness and lets an uncovered camera see you. |
| `touch_safe` | none | Touch the safe door. |
| `uncover_robot` | none | Pull your sack off the robot’s head. |
| `use_smoke` | none | Deploy your single smoke capsule: both sides lose sight for 3 rounds. |
| `wait` | none | Do nothing for a round. |
